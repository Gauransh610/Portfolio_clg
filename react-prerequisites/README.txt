REACT PREREQUISITES - ASSIGNMENTS

This folder has the 8 HTML files and db.json.

Open assignment1.html to assignment7.html in your browser.
Assignment 7 needs an internet connection to get the users from the API.

To run Assignment 8:
1. Install Node.js.
2. Open a terminal inside this folder.
3. Run:

   npx json-server --watch db.json --port 3000

4. Keep the terminal running.
5. Open assignment8.html. You can use VS Code Live Server if needed.

The files use basic HTML, CSS and JavaScript. No React is used.
